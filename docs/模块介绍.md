# Ragent AI 项目模块总结
Ragent AI 是基于 Java + Spring Boot 构建的 Agentic‑RAG 智能体项目，采用 Maven 多模块拆分，一共4大后端模块：**bootstrap、framework、infra‑ai、mcp‑server**，外加 React+TS 前端工程。

## 模块依赖关系
- `bootstrap`（业务主入口）依赖 `framework`（通用基础）、`infra‑ai`（AI能力层）
- `mcp‑server`：独立SpringBoot服务，实现MCP工具调用协议

### 1. framework｜通用基础设施层
无业务逻辑，全项目通用底层组件：
1. **统一数据模型**：`Result<T>`统一返回体、对话请求/消息、向量检索块实体
2. **异常体系**：错误码枚举、业务异常基类、全局异常处理器，兼容Sa‑Token鉴权异常
3. **跨线程上下文**：基于`TransmittableThreadLocal`实现用户上下文、RAG链路追踪上下文，适配异步线程池
4. **通用能力**：幂等注解、SSE发送工具（线程安全，防止连接关闭报错）

### 2. infra‑ai｜AI模型基础设施层
大模型适配网关，屏蔽各家大模型接口差异，向上提供统一接口，核心四大子包：
1. **chat对话**：多平台客户端（百炼、SiliconFlow、Ollama）；支持流式/非流式调用；SSE解析、流式取消、异步执行
2. **embedding向量化**：多厂商Embedding客户端
3. **rerank重排序**：检索结果重排序，有空实现兜底
4. **model模型路由容错（核心）**
    - ModelSelector：根据场景筛选候选模型，过滤熔断模型
    - ModelRoutingExecutor：候选模型依次尝试调用，失败自动降级
    - ModelHealthStore：熔断器实现 CLOSED/OPEN/HALF‑OPEN 三态，维护模型健康状态
> 核心价值：多模型候选、自动熔断降级，解决大模型服务不稳定问题。

### 3. bootstrap｜业务主模块（系统启动入口）
业务全部在此，划分多个业务包：
1. **rag 对话核心**：完整RAG会话链路
    - 记忆管理：短期会话记忆 + 长期摘要记忆落库
    - 查询改写、意图识别、歧义引导
    - 多通道检索：全局向量检索、意图定向检索；检索后去重、重排序后处理
    - Prompt组装，SSE流式返回回答给前端
2. **ingestion 文档ETL流水线**：可编排DAG流水线
    > 获取文档→解析→内容增强→文本分块→后处理→向量化入库Milvus
    > 支持条件分支、环路检测，适配PDF/Markdown/URL/S3等数据源
3. **knowledge知识库管理**：知识库、文档、文档块三级CRUD；定时同步任务，分布式锁防重复执行
4. **admin后台仪表盘**：会话、文档、token消耗等指标统计
5. **user用户认证**：Sa‑Token实现登录鉴权
6. **core工具包**：多种文本切块策略、多格式文档解析器

### 4. mcp‑server｜独立MCP工具服务
实现Model Context Protocol(JSON‑RPC2.0)，负责大模型外部工具调用：
1. 协议层：接收HTTP `/mcp` 请求，分发`initialize`、`tools/list`、`tools/call`
2. 工具注册机制：实现`MCPToolExecutor`接口并注册Bean即可新增工具，无需修改框架代码
3. 内置示例工具：天气查询、工单查询

## 配套工程&资源
1. **frontend**：React18+TS+Vite+Tailwind前端
2. **resources**：建表SQL、初始化脚本、docker-compose部署文件、版权模板
3. **scripts**：运维压测脚本

## 技术栈
Java17 + SpringBoot3.5.7；PostgreSQL+Pgvector向量库；Redis；Apache Tika文档解析；Sa‑Token鉴权；OkHttp；Maven多模块。
